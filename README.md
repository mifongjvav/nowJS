# nowJS

这是一个全新的now的续作

与KN使用相同的技术栈——PixiJS，但是我们使用的版本更高

---

## 为什么要出续作

因为编程猫饱受争议的用户协议问题，大致内容是：你的作品不属于你

而且KN的优化极其低下（虽然now的优化已经非常好了（经临时询问大部分用户都觉得还不错））

最重要的是，KN的限制太多导致它不足以让我去做出更好玩的游戏

尽管我做了一堆lib，但是那也只能扩展部分功能，没法扩展音频这些底层的高级功能

## 为什么选择JS而不是其他的语言

1. 这是我学过最适合做游戏的语言（我知道你要说Lua，已经有HateNeko了所以我不会考虑）
2. JS天生为GUI而生，库多到根本用不完
3. 我需要跨平台

### 为什么不使用TypeScript

正在考虑迁移，敬请期待

### 为什么需要跨平台

1.我不喜欢一次编写，到处调试
2.我是Linux用户，天生不喜欢Windows

## 与原作相比，有什么区别

- 更好的osu谱读取功能
    - 滑条
    - banana
    - 视频/故事版
    - 兼容旧版数值事件语法（如 osu file format v5 故事板）
    - 故事板 Pass/Fail 层与休息段通过/失败判定
    - 休息段成功/失败图标闪烁、最后 3 秒倒计时与音效
    - 4:3 故事板按 4:3 渲染，两侧补黑边
    - 游戏内判定线、统计栏等跟随背景主题色
    - Catch 盘子底部跟随 combo 颜色，Mania 4K 盘子底部跟随轨道颜色
    - 故事板缺失皮肤元素时回退到内置经典皮肤资源
    - osu!mania 谱面默认转换为 4K（D F J K 打击，可开关长条尾判），也可随时切回 Catch
    - 使用谱面自定义 combo 颜色；Mania 4K 使用前 4 个颜色作为轨道色
    - MDUI 主题色从谱面背景自动提取，未选择谱面时恢复默认配色
- 更好的效果
    - 模糊
    - MDUI
- 更轻量（约10MB，原作约200MB）
